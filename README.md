# InspeXion AI

Inspexion AI is a modern Flutter mobile application designed for AI-powered inspection workflows, professional report generation, and digital documentation. The app helps users capture photos, analyze findings, organize inspection data, and export polished PDF reports for clients, teams, and stakeholders.

## Overview

Inspexion AI is built for professionals who need to:
- Capture inspection photos on-site
- Add notes and annotations
- Review AI-assisted findings and recommendations
- Generate professional PDF reports
- Share and export reports quickly
- Maintain inspection history and project records

## Features

- AI-assisted inspection analysis
- Photo capture and annotation
- Smart report generation with PDF export
- Inspection history and project tracking
- User authentication and secure access
- Modern and responsive mobile UI for Android and iOS
- Offline-friendly workflow for field use

## Download APK

This project is built and packaged using GitHub CI/CD.

To download the latest Android APK:

1. Open the GitHub repository
2. Go to the `Actions` tab
3. Open the latest successful workflow run
4. Download the generated APK artifact from the workflow summary
5. Install the APK on your Android device

> The APK is produced automatically by GitHub Actions, so the latest build is available from the CI/CD pipeline.
